# hello_wioterminal

Seeed Wio Terminal 内蔵の LCD に `Hello From Dart !` を表示するサンプル。
`print`/`sleep` だけでなく、注釈バインディング（`packages/wio_terminal`）を
経由する最初のサンプルです。

```dart
import 'dart:io';

import 'package:wio_terminal/wio_terminal.dart';

void main() {
  final display = newDisplay();
  display.drawText(40, 120, 'Hello From Dart !');
  while (true) {
    sleep(const Duration(seconds: 1));
  }
}
```

## 必要なもの

- Dart SDK 3.x
- Go と [TinyGo](https://tinygo.org/getting-started/install/)（TinyGo 0.42.0 で確認）
- USB で接続した Wio Terminal

## 実行手順

```sh
# 1. サンプルの依存解決（初回のみ）
cd examples/hello_wioterminal
dart pub get

# 2. Go に変換（main.go と go.mod を書き出し、続けて `go mod tidy` を実行）
cd ../../packages/dart2tinygo
dart run bin/dart2tinygo.dart build ../../examples/hello_wioterminal/main.dart \
  -o ../../examples/hello_wioterminal/build

# 3. 書き込み
cd ../../examples/hello_wioterminal/build
tinygo flash -target=wioterminal .
```

画面が黒くなり、横向きで白い文字が表示されます。手動でコピーしたい場合は
`tinygo build -target=wioterminal -o firmware.uf2 .` で UF2 ファイルを作れます。

## 生成される Go

```go
// Code generated by dart2tinygo. DO NOT EDIT.
package main

import (
	wio "github.com/o-ga09/dart2tinygo/packages/wio_terminal/go"
	"time"
)

func main() {
	display := wio.NewDisplay()
	display.DrawText(40, 120, "Hello From Dart !")
	for {
		time.Sleep(1 * time.Second)
	}
}
```

ILI9341/SPI/バックライトの扱いはすべてバインディングの Go 側
（`packages/wio_terminal/go`）にあり、生成された `go.mod` はチェックアウト先を
指す `replace` ディレクティブでそれを参照します。
