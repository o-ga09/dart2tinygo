ボード自身のユーザーLEDを点滅させるサンプル。ボード非依存 — 同じ `main.dart` が
[`tinygo_machine`](../../packages/tinygo_machine) 経由で任意の TinyGo ターゲット向けに
ビルドできる。Wio Terminal 専用の
[`hello_wioterminal`](../hello_wioterminal) とは対照的。

```dart
import 'dart:io';

import 'package:tinygo_machine/tinygo_machine.dart';

void main() {
  final led = Pin.led..configure(PinMode.output);
  var count = 0;
  while (true) {
    led.toggle();
    count++;
    print('blink $count');
    sleep(const Duration(milliseconds: 500));
  }
}
```

## 必要なもの

- Dart SDK 3.x
- Go と [TinyGo](https://tinygo.org/getting-started/install/)（TinyGo 0.42.0 で確認）
- USB で接続した TinyGo 対応ボード（Wio Terminal と Raspberry Pi Pico で確認）

## 実行手順

```sh
# 1. 依存解決（初回のみ。リポジトリルートで実行 — pub workspace）
dart pub get
dart pub global activate dart2tinygo   # 一度だけ。`dart2tinygo` CLI をインストールする

# 2. Go に変換して書き込み — ボードに合わせて TinyGo ターゲットを指定
dart2tinygo flash examples/blinky/main.dart \
  -o examples/blinky/build --target=wioterminal   # 例: pico なら --target=pico
```

## 生成される Go

```go
// Code generated by dart2tinygo. DO NOT EDIT.
package main

import (
	tgm "github.com/o-ga09/dart2tinygo/packages/tinygo_machine/go"
	"strconv"
	"time"
)

func main() {
	led := tgm.LED
	led.Configure(tgm.PinOutput)
	count := 0
	for {
		led.Toggle()
		count++
		println("blink " + strconv.Itoa(count))
		time.Sleep(500 * time.Millisecond)
	}
}
```

`tgm.LED`/`.Configure`/`.Toggle`（`packages/tinygo_machine/go/machine.go`）は
TinyGo 自身の `machine.LED`/`machine.Pin.Configure`/`.Set` をラップしており、
これは全ての TinyGo ターゲットが定義するもの — `wioterminal`/`pico` の両方で
`tinygo build` を確認済み。
