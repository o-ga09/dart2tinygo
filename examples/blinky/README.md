Blinks the board's own user LED. Board-agnostic — the same `main.dart`
builds for any TinyGo target via
[`tinygo_machine`](../../packages/tinygo_machine), unlike
[`hello_wioterminal`](../hello_wioterminal), which is Wio Terminal-only.

```dart
import 'dart:io';

import 'package:tinygo_machine/tinygo_machine.dart';

void main() {
  final led = Pin.led..configure(PinMode.output);
  var count = 0;
  while (true) {
    led.toggle();
    count++;
    print('blink $count');
    sleep(const Duration(milliseconds: 500));
  }
}
```

## Requirements

- Dart SDK 3.x
- Go and [TinyGo](https://tinygo.org/getting-started/install/) (tested with TinyGo 0.42.0)
- A TinyGo-supported board connected over USB (tested with the Wio Terminal
  and Raspberry Pi Pico)

## Run

```sh
# 1. Resolve dependencies (once, at the repository root — it is a pub workspace)
dart pub get

# 2. Convert to Go and flash — pick the TinyGo target for your board
cd packages/dart2tinygo
dart run bin/dart2tinygo.dart flash ../../examples/blinky/main.dart \
  -o ../../examples/blinky/build --target=wioterminal   # or e.g. --target=pico
```

## Generated Go

```go
// Code generated by dart2tinygo. DO NOT EDIT.
package main

import (
	tgm "github.com/o-ga09/dart2tinygo/packages/tinygo_machine/go"
	"strconv"
	"time"
)

func main() {
	led := tgm.LED
	led.Configure(tgm.PinOutput)
	count := 0
	for {
		led.Toggle()
		count++
		println("blink " + strconv.Itoa(count))
		time.Sleep(500 * time.Millisecond)
	}
}
```

`tgm.LED`/`.Configure`/`.Toggle` (`packages/tinygo_machine/go/machine.go`)
wrap TinyGo's own `machine.LED`/`machine.Pin.Configure`/`.Set`, which every
TinyGo target defines — verified with `tinygo build` for both `wioterminal`
and `pico`.
