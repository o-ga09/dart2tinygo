# tinygo_annotations (package)

**Languages:** English | [日本語](./README.ja.md)

A package intended to provide annotations (`@GoImport` / `@GoName` / `@GoType`) that let binding authors declare the Go-side counterparts from the Dart side.

Not implemented yet (skeleton only). See [docs/writing_bindings.md](../../docs/writing_bindings.md) for details.
